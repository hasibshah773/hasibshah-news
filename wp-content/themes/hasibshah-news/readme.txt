HasibShah News is an authoritative, high-performance, and responsive WordPress theme tailored for Bangladeshi digital newspapers, news portals, and editorial magazines.

== Description ==

HasibShah News provides a professional editorial broadsheet layout with seamless support for both Bangla (বাংলা) and English typography. Designed according to modern WordPress coding standards and Theme Review guidelines, it combines clean PHP templates, Gutenberg block styling via `theme.json` (v3), fluid clamp typography, accessible navigation, and optional Elementor page builder compatibility.

Key Features:
* Clean, modular PHP template architecture adhering strictly to WordPress Coding Standards.
* Bilingual typography with native support for Bangla conjunct characters, diacritics, and headline overflow prevention.
* Live Breaking News Ticker with accessible pause controls, hover-pause, and reduced-motion support.
* Dynamic editorial homepage layout featuring Hero Lead Stories, Opinion & Editorial Columnists, District News Grid, and Media Highlights.
* Comprehensive single article view with bilingual publication dates, estimated reading time, author bylines, social sharing, and related stories.
* Accessible threaded comments with full schema markup and keyboard navigation.
* Complete template hierarchy: category, archive, author, search (with empty state), and custom 404 page with Bangla numerals.
* Optional Elementor Canvas and Full-Width template compatibility without making Elementor a required dependency.
* 100% self-hosted assets: zero external CDN or Google Fonts requests for complete privacy and GDPR compliance.
* Built-in layout shift (CLS) prevention with reserved advertisement slots and responsive media containers.
* Translation-ready with complete gettext localization and standard text domain.

== Installation ==

1. In your WordPress admin dashboard, navigate to Appearance -> Themes.
2. Click Add New, then click Upload Theme.
3. Upload the `hasibshah-news.zip` theme package and click Install Now.
4. Click Activate to set HasibShah News as your active theme.

== Frequently Asked Questions ==

= Does HasibShah News require Elementor? =
No. Elementor is completely optional. HasibShah News works natively out of the box with standard WordPress Gutenberg blocks and classic widgets.

= Does this theme collect user data or make external CDN calls? =
No. HasibShah News does not load external Google Fonts, CDN scripts, or third-party tracking resources. All font files and scripts are 100% self-hosted for maximum privacy, security, and GDPR compliance.

= How do I translate the theme? =
The theme includes a translation template file located at `languages/hasibshah-news.pot`. You can use tools like Poedit or plugins like Loco Translate to translate the theme into any language.
