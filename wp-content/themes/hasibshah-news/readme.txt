HasibShah News is an authoritative, high-performance, and responsive WordPress theme tailored for Bangladeshi digital newspapers, news portals, and editorial magazines.

== Description ==

HasibShah News provides a professional editorial broadsheet layout with seamless support for both Bangla (বাংলা) and English typography. Designed with modern WordPress standards, it includes full Gutenberg styling via `theme.json` (v3) while maintaining clean PHP templates and optional Elementor page compatibility.

Key Features:
* Clean, modular PHP template architecture.
* Built-in support for Bangla diacritics and overflow prevention.
* Optimized queries and zero premature caching overhead.
* 100% self-hosted assets with zero third-party CDN dependencies.
* Accessible navigation and semantic HTML5 markup.
* Optional Elementor Canvas and Full-Width support.

== Installation ==

1. In your WordPress admin dashboard, navigate to Appearance -> Themes.
2. Click Add New, then click Upload Theme.
3. Upload the `hasibshah-news.zip` theme package and click Install Now.
4. Click Activate to set HasibShah News as your active theme.

== Frequently Asked Questions ==

= Does HasibShah News require Elementor? =
No. Elementor is completely optional. HasibShah News works out of the box with standard WordPress blocks and classic widgets.

= Does this theme collect user data or make external CDN calls? =
No. HasibShah News does not load external Google Fonts or third-party tracking scripts. All assets are self-hosted for maximum privacy and GDPR compliance.
